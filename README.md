🎄 Magia do Natal - Frases, Cartões e Surpresas
Um aplicativo web interativo, festivo e responsivo desenvolvido com HTML5, Tailwind CSS (CDN) e JavaScript vanilla para celebrar o Natal com mensagens inspiradoras, um criador de cartões personalizáveis com temas visuais e imagens festivas, e uma surpresa especial do Papai Noel.

🚀 Funcionalidades Principais
❄️ Efeito de Neve Dinâmico: Animação leve de queda de flocos de neve em tempo real em todas as telas.

📖 Mural de Frases: Frases natalinas divididas por categorias (Família, Amigos, Romance e Curtas para Status) com cópia rápida para a área de transferência.

🎨 Criador de Cartões Interativo:

Personalização do destinatário, mensagem e remetente com pré-visualização ao vivo.

Seletor de Temas Visuais: Opções como Clássico (Vermelho), Floresta (Verde), Luxo Dourado (Dourado), Noite Estelar (Azul Escuro), Neve Alpina (Cinza Gelo) e Rosa Natalino.

Gerenciador de Imagens de Natal: Escolha rápida de ícones/adesivos festivos ilustrativos (Árvore, Papai Noel, Presentes, Estrela) ou inserção de URL de imagem personalizada.

Botões de Envio e Compartilhamento: Copiar mensagem completa e botão direto para envio via WhatsApp.

🎅 Surpresa do Papai Noel: Gerador interativo de conselhos e mensagens mágicas do bom velhinho.

🛠️ Tecnologias Utilizadas
HTML5 & JavaScript (ES6+)

Tailwind CSS (via CDN) para estilização moderna e responsiva

FontAwesome (v6.4.0) para ícones festivos e de interface

Google Fonts (Mountains of Christmas e Poppins)

💻 Como Executar o Projeto
Baixe ou copie o código fonte completo (index.html).

Salve o arquivo com o nome index.html em seu computador.

Dê um duplo clique no arquivo salvo para abri-lo em qualquer navegador web moderno (Google Chrome, Firefox, Edge, Safari).
